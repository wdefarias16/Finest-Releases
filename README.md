# finest · Finanzas en Pareja

Descargas de la app de escritorio para Windows. Están en **[Releases](../../releases/latest)**.

| Archivo | Para qué |
|---|---|
| `Finanzas-Setup-<versión>.exe` | **Instalador (recomendado).** Instala la app con su base de datos incluida; no hay nada que configurar. |
| `Finanzas-<versión>-portable.zip` | La app lista para usar sin instalar: descomprime y abre `Finanzas\Finanzas.exe`. |

Requisitos: Windows 10 u 11 de 64 bits.
